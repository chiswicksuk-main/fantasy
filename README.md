# J1 Fantasy 2026/27

A small fantasy football game for the 2026/27 Meiji Yasuda J1 League. It's a static page: `index.html`, `style.css` and `app.js`, with no framework and no build step. Everything you do is saved in the browser's localStorage.

## Run it

The page reads `data/*.json` with `fetch`, and browsers block that when you open the file directly, so serve the folder:

```sh
cd fantasy
python3 -m http.server 8000
# open http://localhost:8000 (or your computer's LAN IP on a phone)
```

It also works on any static host, such as GitHub Pages or Netlify.

## How to play

1. **Squad**: pick 15 players (2 GK, 5 DEF, 5 MID, 3 FWD) with 100m, at most 3 from one club. Search by English or Japanese name, filter by club and position, and watch the bank. Changes are free until you press **Save squad**. After that you get 1 free transfer per gameweek, and each extra transfer costs 4 points. Undoing a transfer in the same gameweek gives it back.
2. **Lineup**: tap a player, then tap another to swap them. Your starting XI needs 1 GK, 3–5 DEF, 2–5 MID and 1–3 FWD. Pick a captain, who scores double. Order the bench with ▲▼. If a starter plays 0 minutes, bench players come on in that order, as long as the formation stays legal (a GK only replaces a GK).
3. **Results**: import the real stats for a gameweek (see below). The app scores every manager and shows a breakdown for each player. Results lock that gameweek. Press **Start GW N+1** to move on, which freezes everyone's lineup for the finished week.
4. **League**: up to 8 managers on one device. Tap a row to switch manager. **Export league file** saves everything to one JSON file. A friend can **Import** it on their phone, and importing adds or updates managers and results.

## Scoring

| Event | GK | DEF | MID | FWD |
|---|---|---|---|---|
| Plays 1–59 min | 1 | 1 | 1 | 1 |
| Plays 60+ min | 2 | 2 | 2 | 2 |
| Goal | 6 | 6 | 5 | 4 |
| Assist | 3 | 3 | 3 | 3 |
| Clean sheet (60+ min) | 4 | 4 | 1 | – |
| Every 3 saves | 1 | – | – | – |
| Yellow / Red | −1 / −3 | | | |
| Own goal / Pen missed | −2 / −2 | | | |
| Pen saved | 5 | | | |

A player with 0 minutes scores nothing. If the captain doesn't play, nobody gets double points.

## Stats files

Paste the CSV, upload it, or save it as `data/stats_gwN.csv` (for example `data/stats_gw13.csv`) and press **Load**:

```csv
playerId,minutes,goals,assists,cleanSheet,saves,yellow,red,ownGoal,pensMissed,pensSaved
KAS-40,90,1,0,0,0,0,0,0,0,0
KAS-1,90,0,0,1,4,0,0,0,0,0
```

- `playerId` is the `id` in `data/players.json`. That's the club code plus the shirt number, such as `KAS-40` for Yuma Suzuki.
- `cleanSheet` takes `1`/`0` or `true`/`false`.
- Any player not in the file counts as 0 minutes. Unknown ids are skipped, and the app tells you which.
- **Blank template** downloads a file that lists every player, with names, so you only have to fill in the numbers.

## Data

The game only reads `data/players.json` and `data/fixtures.json`.

`players.json` is generated by `tools/build-players.mjs`:

```sh
node tools/build-players.mjs
```

- If `data/seed.csv` exists, the script builds the player list from that file only. Columns: `club,name,position` are required. `nameJa,number,role,price,status,verified,id,note` are optional. If `price` is blank, it comes from `role`.
- Otherwise the script uses `tools/roster.csv`. I compiled that list in October 2026 from 2026/27 squad announcements by the clubs and the J.League, and from DAZN/Gekisaka coverage of those announcements, all found through web search.

**Pricing** (`priceFor` in `tools/build-players.mjs`) is a single table of role × position:

| role | GK | DEF | MID | FWD |
|---|---|---|---|---|
| star | 10 | 11 | 12.5 | 14 |
| starter | 9 | 9 | 9.5 | 10 |
| solid | 6 | 6.5 | 7 | 8 |
| rotation | 4 | 4.5 | 5 | 5 |
| fringe | 3 | 3.5 | 3.5 | 4 |

The role for each player is a judgement call. You can change it in the CSV and rebuild.

`status` is `unknown` for everyone because injury and suspension news wasn't researched. Set `injured` or `suspended` in the CSV and the app shows a badge.

`fixtures.json` lists the 38 rounds, but only rounds 12–13 have matches so far. The app uses them to show each player's next opponent.
